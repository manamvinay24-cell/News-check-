About NewsCheck


            

                NewsCheck is a Fake News Detection System that uses
                Natural Language Processing, TF-IDF feature extraction,
                and a trained Logistic Regression model to classify
                submitted news content.
            


            

                Image analysis uses OCR to extract text before prediction.
                The result is a model-based prediction and should not be
                treated as an independently verified fact-check.
